# Expense Tracker

A simple tool to log income and expenses, see your balance, and filter by category. Built to understand how state management works in plain JavaScript before reaching for a library.

---

## Features

- Add income and expense entries with a label and amount
- See running balance update in real time
- Filter transactions by category
- Color-coded totals (green for income, red for expenses)
- Data persists in localStorage

---

## Running it

```bash
git clone https://github.com/kunalshahdev/expense-tracker.git
```

Open `index.html`. That's it.

---

## Stack

HTML · CSS · Vanilla JavaScript

---

## What I learned

Managing a list of objects in JS and keeping the UI in sync with state without any framework. Also how quickly a small app can grow if you don't plan the data structure first.
